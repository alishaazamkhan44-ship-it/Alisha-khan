# ALISHA KHAN Website

This package preserves the uploaded ALISHA KHAN website. The original HTML, CSS, JavaScript,
content, and placeholders have not been rewritten or rebranded.

## Publish with GitHub Pages
1. Extract this ZIP.
2. Upload `index.html`, `.nojekyll`, and `README.md` directly into the root of your GitHub repository.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.

The main page must remain named exactly `index.html` and must be in the repository root.

Note: The original website contains its own `[EDIT]` placeholders and its original contact-form behavior.
Those have been preserved, not filled in or changed.
